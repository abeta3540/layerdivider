# サン・アース拠点マップ

サン・アース株式会社の [サービス拠点案内](https://www.sun-earth.jp/about-us/service-office/) を元にした、
日本の陸地シルエットだけを表示するカスタムSVG地図で拠点を確認できるツールです。
地図タイルではなく自前のSVGなので、外部の地図サービスへの通信なしに完全オフラインで動作します。

## 機能

- 日本の海岸線データのみで構成した地図（他国・県境・海洋名などの表記なし）
- 本社・支店 / 関連施設（部品庫・マシンパーク等） / 販売店・代理店 の3カテゴリで色分けしたピン表示
- 各ピンから引き出し線（リーダーライン）を伸ばし、拠点名と住所を常時ラベル表示
  （近接する拠点同士やピンとラベルが重ならないよう自動配置）
- サイドバーの拠点一覧から選択すると詳細（電話番号・Googleマップリンク）を展開表示
- 拠点名・住所によるキーワード検索、カテゴリでの絞り込み

## 使い方

静的ファイルのみで動作します。`index.html` をブラウザで開くか、簡易サーバーを立てて閲覧してください。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## ファイル構成

- `index.html` — ページ構造
- `style.css` — スタイル（ダークモード対応）
- `map-data.js` — 日本の陸地シルエットのSVGパスデータと座標変換関数（`JAPAN_MAP` / `projectLatLng`）
- `data.js` — 拠点データ（`OFFICES`）とカテゴリ定義（`GROUPS`）
- `app.js` — SVG地図描画・引き出し線ラベルの自動配置・検索・フィルタのロジック
- `build-standalone.sh` — 上記4ファイルを1つのHTMLファイルに結合するビルドスクリプト

## 注意事項

- 地図上のピン座標は住所（市区町村〜字レベル）から推定したおおよその位置です。正確な地点はサイドバーの「Googleマップで見る」リンクで確認してください。
- 地図の陸地データは [japanmap](https://github.com/SaitoTsutomu/japanmap)（Saito Tsutomu 作, Apache License 2.0）の境界データを結合・単純化して生成しています。沖縄・離島は表示範囲外です。
