# サン・アース拠点マップ

サン・アース株式会社の [サービス拠点案内](https://www.sun-earth.jp/about-us/service-office/) を元にした、
リアル調（国土地理院タイル）の日本地図で拠点を確認できるツールです。

## 機能

- 国土地理院タイルによるリアル調の日本地図（標準地図／淡色地図／航空写真を切り替え可能）
- 本社・支店 / 関連施設（部品庫・マシンパーク等） / 販売店・代理店 の3カテゴリで色分けしたピン表示
- サイドバーの拠点一覧から選択するとその拠点へ地図が移動しポップアップを表示
- 拠点名・住所によるキーワード検索、カテゴリでの絞り込み
- 各拠点のポップアップから電話発信リンク・Googleマップでの正確な住所検索が可能

## 使い方

静的ファイルのみで動作します。`index.html` をブラウザで開くか、簡易サーバーを立てて閲覧してください。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## ファイル構成

- `index.html` — ページ構造
- `style.css` — スタイル（ダークモード対応）
- `data.js` — 拠点データ（`OFFICES`）とカテゴリ定義（`GROUPS`）
- `app.js` — Leaflet.js を使った地図描画・検索・フィルタのロジック

## 注意事項

- 地図上のピン座標は住所（市区町村〜字レベル）から推定したおおよその位置です。正確な地点はポップアップ内の「Googleマップで見る」リンクで確認してください。
- 地図タイルは [国土地理院](https://maps.gsi.go.jp/development/ichiran.html)、地図ライブラリは [Leaflet](https://leafletjs.com/) を利用しています（いずれもブラウザから直接読み込むため、閲覧にはインターネット接続が必要です）。
